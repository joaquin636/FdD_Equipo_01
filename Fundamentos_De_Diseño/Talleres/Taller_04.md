El sistema incorpora diferentes dispositivos, entre ellos un dispositivo montado en la cabeza, un chaleco, una faja, una muñequera y un bastón. Utiliza diferentes sensores, como sensores infrarrojos, sensores ultrasónicos, cámaras y GPS, para obtener información del entorno. Los datos obtenidos permiten detectar obstáculos y proporcionar asistencia al usuario en diferentes escenarios. | |

## PATENTE 2

### Mochila de navegación y evitación de obstáculos para personas ciegas

| **CAMPO** | **INFORMACIÓN** |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **TÍTULO** | MOCHILA DE NAVEGACIÓN Y EVITACIÓN DE OBSTÁCULOS PARA PERSONAS CIEGAS |
| **N° PUBLICACIÓN** | [CN215607427U](https://worldwide.espacenet.com/patent/search?q=pn%3DCN215607427U) |
| **IPC** | A61H3/06 ; G01S15/93 |
| **SOLICITANTE** | GUANGZHOU HEIJIA TECH CO LTD |
| **INVENTOR** | DONG HANLIN |
| **FECHA DE PUBLICACIÓN** | 25/01/2022 |
| **¿QUÉ APORTA A NUESTRO PROYECTO?** | Aporta directamente el principio de detectar la distancia entre el usuario y un obstáculo y convertir esta información en una señal vibratoria. Este principio se relaciona directamente con nuestro chaleco, ya que los sensores detectarán obstáculos y los vibradores alertarán al usuario antes de una posible colisión. |
| **CARACTERÍSTICAS RELACIONADAS** | Detector de distancia, vibrador, placa de control, dispositivo portátil, detección de obstáculos, detección de peatones y alerta mediante vibración. |
| **VALORES** | Seguridad, prevención, autonomía, accesibilidad e independencia. |

| **RESUMEN** | **IMÁGENES** |
| -------------------- | -------------------- |
| El modelo de utilidad describe una mochila de navegación para personas ciegas que incorpora un sistema de evitación de obstáculos. El dispositivo cuenta con una placa de control, un detector de distancia y un vibrador. El detector identifica la distancia entre el usuario y los obstáculos o peatones ubicados delante de él y transmite esta información a la placa de control. Cuando se detecta un posible obstáculo, el vibrador proporciona una señal al usuario para advertirle y permitirle evitar una colisión, mejorando así su seguridad durante el desplazamiento. | |

## PATENTE 3

### Equipos de asistencia para caminar para personas con discapacidad visual

| **CAMPO** | **INFORMACIÓN** |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **TÍTULO** | EQUIPOS DE ASISTENCIA PARA CAMINAR PARA PERSONAS CON DISCAPACIDAD VISUAL |
| **N° PUBLICACIÓN** | [CN221731468U](https://worldwide.espacenet.com/patent/search?q=pn%3DCN221731468U) |
| **IPC** | A61F9/08 ; A61H3/06 |
| **SOLICITANTE** | TAXI MAIMAITI TUERXUN |
| **INVENTOR** | PAKEZHATI TAXI MAIMAITI |
| **FECHA DE PUBLICACIÓN** | 20/09/2024 |
| **¿QUÉ APORTA A NUESTRO PROYECTO?** | Aporta el uso combinado de un sensor para detectar obstáculos y un módulo de vibración para transmitir información al usuario con discapacidad visual. Este principio se relaciona con nuestro chaleco, que utilizará sensores de proximidad y vibradores para comunicar la presencia y cercanía de obstáculos. |
| **CARACTERÍSTICAS RELACIONADAS** | Sensor infrarrojo, detección de obstáculos, módulo de vibración, dispositivo portátil, alerta táctil y asistencia para personas con discapacidad visual. |
| **VALORES** | Seguridad, autonomía, inclusión, accesibilidad y confianza. |

| **RESUMEN** | **IMÁGENES** |
| -------------------- | -------------------- |
| El modelo de utilidad describe un equipo auxiliar para caminar destinado a personas con discapacidad visual. El dispositivo incorpora un bastón, un mango, un sensor infrarrojo, un altavoz, una luz de alarma y un módulo de vibración. El sensor permite detectar obstáculos alrededor del usuario y, mediante el módulo de vibración, proporciona información al usuario a través del mango. De esta manera, el sistema facilita la detección de obstáculos y mejora la seguridad y flexibilidad durante el desplazamiento. | |
